Adding the repository (when published)

For Debian $SUITE on AMD64 or ARM64. Use the matching suite from the table for other Debian versions. Before trusting a third-party repository, verify its permanent signing key fingerprint through an independent channel.

1. Install the production archive key into /etc/apt/keyrings/:

$KEY_COMMAND

2. Add a deb822 source file with a scoped Signed-By key (no apt-key):

$SOURCES_COMMAND

3. Refresh APT and explicitly select the archive version:

$INSTALL_COMMAND

Only binary packages are provided; no deb-src index. The repository uses backports-style APT priorities, so installation of an archive version should be requested explicitly.
